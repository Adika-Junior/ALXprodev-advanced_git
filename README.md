ALXprodev Advanced Git – GitFlow Practice
=========================================

This repository is used to practice an end‑to‑end **GitFlow** workflow:

- Initializing a Git repository and configuring GitFlow (`develop`, feature, release, and master branches).
- Working with feature branches such as `feature/implement-login` and `feature/implement-signup`.
- Creating and finishing release branches (e.g. `release/1.0.0`) and tagging releases (e.g. `v1.0.0`).
- Implementing Git hooks (`pre-commit` and `post-merge`) to enforce README presence and log merges.

The goal is to understand and automate a professional Git branching and release process.
